# 공무원 한글문서 편집스킬 — 한글 보고서를 만들어 주는 AI 스킬

**부르는 이름(호출명): `/gongyong-hwpx`**

견본 한글 파일을 올리고 쓸 내용만 말하면, **그 양식 그대로 한글(.hwpx) 보고서**를 만들어 줍니다.

- 견본이 없으면 기본 보고서 양식(제목 상자·요약 상자·□○-·표·참고)으로 작성
- 줄 끝·이름표 폭·표 칸 너비·쪽 나눔 등 서식 손질은 도구가 자동 처리 ⇒ 작성자는 내용 검토에 집중
- **대구시청 현직 공무원**이 보고서 서식 손질에 드는 시간을 줄이려고 직접 만들었습니다. 업무 현장에서 쓰는 서식 원칙을 그대로 담았습니다

## 설치 (한 번만)

| 쓰는 곳 | 설치 순서 | 참고 |
|---|---|---|
| **Claude 앱** | ① 설정 → 기능 → '클라우드에서 코드 실행' 켜기 ② 사용자 지정 → Skills → + 추가 → Skill 업로드 ③ 받은 파일 올리고 켜기 | 무료 요금제부터 가능, **한글 파일까지 완성** |
| **ChatGPT** | ① 플러그인 → 스킬 ② 추가 → 컴퓨터에서 업로드 ③ 받은 파일 올리면 바로 사용 | Plus 요금제에서 **한글 파일까지 확인** |
| **Gemini** (웹·Mac 앱) | ① 맞춤설정 → 스킬 → 만들기 ② 업로드하기 ③ 대화에서 `@스킬 이름`으로 부르기 | 한글 파일 작성은 아직 확인 못 함(글로 받아 붙여 넣기) |

※ 메뉴 이름은 앱 판에 따라 다를 수 있음('26. 11. 1. 화면 기준)

## 쓰는 법 — 대화창에 이렇게 말하면 됩니다

- 대화창에 **`/gongyong-hwpx`**를 입력해 스킬을 부른 뒤 요청(한글 파일 이야기를 하면 저절로 불리기도 함)
- (견본 파일 첨부) "이 양식대로 ○○ 추진계획(안)을 2쪽으로 써 줘. 내용은 …"
- "견본 없이 기본 양식으로 ○○ 현안 보고서 1쪽, 참고로 추진 일정표를 붙여 줘."
- "사진 두 장은 표에 넣어 줘." (사진도 함께 첨부)
- 결과를 보고 "□ 추진계획에 예산 표를 넣고 1쪽에 맞춰 줘"처럼 고칠 점을 말하면 같은 양식으로 다시 작성

※ 옛 형식 `.hwp`는 읽지 못함 ⇒ 한글에서 [파일] → [다른 이름으로 저장] → 파일 형식 HWPX로 저장해 올리기

## 저절로 맞추는 서식

| 구분 | 내용 |
|---|---|
| 문단 | □○-· 기호·들여쓰기, 괄호 이름표 네 글자 폭(`(현  황)`), 작대기 항목명 세 글자 폭, 끝 줄 한두 글자 올리기 |
| 글자 | 부연설명 괄호 2pt 작게, \*·※ 설명글은 설명하는 글보다 2pt 작게 하고 아래를 조금 띄움(표 밑 ※는 표 글자보다 1pt 작게) |
| 표 | 칸 너비·글자 크기(10~12pt), 표 끝선, 금액은 오른쪽 정렬, 기준·단위 줄, 사진은 칸 배경(비율 유지) |
| 쪽 | ○와 그 아래 내용은 한 쪽에, 참고 쪽은 한 장에 꽉 채움 |
| 짜임 | 근거법령은 늘 1번, 요약 상자는 한 문장 — 벗어나면 알려 줌 |

## 꼭 알아 두세요

- **공개해도 되는 자료만 입력** — AI 앱에 올린 파일·대화는 외부 서비스로 전송됨. 비공개 문서·개인정보 입력 금지, 기관 보안 지침이 있으면 그 지침을 따름
- **숫자·법령 조문·날짜는 작성자가 원문과 대조** — 모르는 값은 `○○`로 비워 두고 알려 줌
- **결재 전 한글에서 열어 확인** — 줄·쪽은 한글 없이 어림해 맞춘 것
- 표지의 슬로건·마크는 대구광역시 것(아래 이용 조건 참고)

- **제외:** 기본 양식 표지의 대구광역시 슬로건·마크 그림(`assets/basic_report.hwpx` 안)은 대구광역시 상징으로 이 라이선스에 들어가지 않음 ⇒ 다른 기관은 표지 없이 쓰거나 자기 기관 견본을 올려 쓰기

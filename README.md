# 공무원 한글문서 편집스킬 — 한글 보고서를 만들어 주는 AI 스킬

**부르는 이름(호출명): `/gongyong-hwpx`** · 지금 판: **v2.12**('26. 11. 10.)

견본 한글 파일을 올리고 쓸 내용만 말하면, **그 양식 그대로 한글(.hwpx) 보고서**를 만들어 줍니다.
줄·간격·표 맞추기 같은 서식 손질은 AI가 하고, 작성자는 내용 검토에만 집중하면 됩니다.

- **대구시청 현직 공무원**이 보고서 서식 손질에 드는 시간을 줄이려고 직접 만들었습니다. 업무 현장에서 쓰는 서식 원칙을 그대로 담았습니다.

## 이런 일을 합니다

| 이렇게 말하면 | 이렇게 됩니다 |
|---|---|
| (견본 파일 첨부) "이 양식대로 ○○ 추진계획(안)을 2쪽으로 써 줘. 내용은 …" | 견본과 같은 글꼴·간격·표 모양으로 새 보고서 |
| "견본 없이 ○○ 현안 보고서 1쪽, 참고로 추진 일정표를 붙여 줘" | 들어 있는 기본 보고서 양식(제목 상자·요약 상자·□○-·표·참고)으로 작성 |
| (이미 쓴 한글 파일 첨부) "이 파일 그대로 정돈해 줘" | **글은 한 글자도 바꾸지 않고** 줄 나눔·맞춤·간격만 손질(원본은 두고 `○○_정돈.hwpx`로) |
| (이미 쓴 한글 파일 첨부) "이 파일 서식 검사해 줘" | 파일은 그대로 두고 고칠 곳만 알려 줌 |
| (칸을 채우는 신청서·안내서 양식 첨부) "이 칸에 써 줘, 5쪽 이내로" | **표 안 보고서** — 양식의 표·칸은 그대로 두고 칸 안에 □○- 글과 작은 표·그림을 넣어 쪽 상한에 맞춤 |

## 쓰는 법

1. 대화창에 **`/gongyong-hwpx`**를 입력해 스킬을 부릅니다(한글 파일 이야기를 하면 저절로 불리기도 함).
2. 견본 파일(있으면)과 자료를 올리고 쓸 내용을 말합니다. 사진도 함께 올리면 표에 넣어 줍니다.
3. 받은 파일을 한글에서 열어 보고, "□ 추진계획에 예산 표를 넣고 1쪽에 맞춰 줘"처럼 고칠 점을 말하면 같은 양식으로 다시 만들어 줍니다.

- 쓸 수 있는 종류: 추진계획(안)·결과 보고·검토 보고·현안 보고·대책 보고·개선방안·회의 자료·행사 계획·주간업무 보고·의회 답변서·언론보도 대응 보고·보도자료·사업설명서 — 종류에 맞는 차례로 씁니다.

**이럴 때는 이렇게**

| 상황 | 이렇게 말하거나 하기 |
|---|---|
| 날짜·부서 줄, 요약 상자, 근거법령, 표 제목을 일부러 빼고 싶을 때 | "날짜 줄은 빼 줘"처럼 말하기 — 뺀 것을 다시 넣으라고 하지 않음 |
| 근거 법령이 하나뿐일 때 | AI가 시행령·조례·지침 등을 더 찾아보고, 없으면 하나로 두고 알려 줌 |
| 이 스킬로 만든 파일을 손으로 고친 뒤 정돈할 때 | 만들 때 맞춘 서식은 그대로 두고 손댄 곳만 다듬음 |
| 쪽 수가 정해진 양식('5쪽 이내') | "5쪽 안에 맞춰 줘" — 간격부터 줄이고, 그래도 넘으면 분명히 알려 줌 |
| 옛 형식 `.hwp` 파일 | 한글에서 [파일] → [다른 이름으로 저장] → 파일 형식 HWPX로 저장해 올리기 |
| PDF·그림으로 된 문서 | "이 PDF 내용 그대로 한글로 옮겨 써 줘"(정돈은 한글 파일만 됨) |

## 저절로 맞추는 서식

- **줄**: 낱말 가운데서 끊기지 않게(어절 단위), 두 줄 넘는 항목은 둘째 줄을 이름표·쌍점 뒤 첫 글자에 맞춤, 끝 줄에 한두 글자만 남지 않게, 줄 끝선이 맞게(끝선에 조금 못 미친 줄은 자간을 조금 늘려)
- **순서 기호**: `Ⅰ.` `1.` `1)` `(1)` `가.` `가)` `(가)` `A.` `a)` `(a)` `①` `❶` `⑴`, 네모 숫자까지 — 기호 뒤 한 칸, 둘째 줄은 글 첫머리에
- **이름표**: `(현    황)`처럼 네 글자 폭으로 맞추고 괄호·쌍점은 위아래 한 줄로
- **글자**: 부연설명 괄호는 조금 작게, ※·* 설명글도 작게, 빈칸은 한 칸, 한글에서 네모로 찍히는 보이지 않는 글자(AI가 쓴 글에 잘 섞임)는 뺌
- **표**: 칸 너비·글자 크기(본문보다 3pt 작게)·표 끝선, ■ 표 제목, 금액은 오른쪽 정렬, 사진은 칸 배경으로
- **쪽**: ○와 그 아래 내용은 한 쪽에, 참고 쪽은 한 장에 꽉 차게
- **짜임**: 근거법령은 늘 1번(법령 이름·조항만), 요약 상자는 결론 한 문장 — 벗어나면 옮기거나 알려 줌

## 꼭 알아 두세요

- **공개해도 되는 자료만 입력** — AI 앱에 올린 파일·대화는 외부 서비스로 전송됩니다. 비공개 문서·개인정보는 넣지 말고, 기관 보안 지침이 있으면 그 지침을 따르세요
- **숫자·법령 조문·날짜는 작성자가 원문과 대조** — 모르는 값은 `○○`로 비워 두고 알려 줍니다
- **결재 전 한글에서 열어 확인** — 줄·쪽은 한글 없이 어림해 맞춘 것입니다
- **여백** — 결과를 줄 때마다 그 문서의 여백을 알려 줍니다(기본 양식은 A4, 본문 칸 사방 20mm). 온나라 공문에 붙여 넣을 때는 [쪽] → [편집 용지]에서 왼쪽·오른쪽 여백을 같게 맞추면 줄 바꿈이 그대로 갑니다(쪽 끝은 붙여 넣은 뒤 확인)
- 기본 양식 표지의 슬로건·마크는 대구광역시 것입니다(아래 이용 조건 참고)

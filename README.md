# 양식 따라 쓰기 — 한글(HWPX) 보고서를 만드는 AI 스킬 (시험판)

견본 한글 파일(.hwpx)을 올리면 **그 양식 그대로**(여백·글꼴·글자 크기·줄 간격·내어쓰기·□○- 기호·표 모양) 새 보고서를 한글 파일로 만들어 주는 AI 스킬입니다. Claude·ChatGPT·Gemini에서 같은 파일을 씁니다(한글 파일까지 만드는 것은 Claude 앱과 ChatGPT(Work 모드)에서 확인).
견본이 없으면 들어 있는 **기본 보고서 양식**(표지·제목 상자·요약 상자·Ⅰ.□○-·표·참고)을 씁니다.

> 시험판입니다. 쓰다가 이상한 점은 이 저장소의 **Issues**(또는 공유받은 게시판)에 남겨 주세요.

**먼저 보기** — [`예시_보고서/`](예시_보고서)에 이 스킬로 만든 **4쪽 기능 견본 보고서**(한글 파일·PDF·미리보기 그림)가 있습니다. 제목·요약 상자, □○-· 체계, 위 첨자 풀이, 비교표, 제목 걸친 상자, 자주 묻는 질문 표, 한 줄·두 줄 흐름도, 화면 그림 표, 기준·단위 줄과 합계 줄이 있는 표를 한 문서에 담았고, 설치 방법도 그 안에 있습니다(한글에서 손으로 고치지 않은 결과 그대로).

## 받기

- **[최신 판 받기](../../releases/latest)** — `gongyong-hwpx.skill` 파일 하나를 받으면 됩니다.
- 업무망 PC에서는 GitHub가 막혀 있을 수 있습니다. Claude 앱을 쓰는 인터넷 PC에서 받으세요.

## 설치 (한 번만) — Claude·Gemini·ChatGPT 모두 같은 스킬 파일

| 쓰는 곳 | 설치 순서 | 참고 |
|---|---|---|
| **Claude 앱** | ① 설정 → 기능 → '클라우드에서 코드 실행' 켜기 ② 사용자 지정 → Skills → + 추가 → Skill 업로드 ③ 받은 `.skill`(zip) 올리고 켜기 | 무료 요금제부터, **한글 파일까지 완성** |
| **Gemini** (웹·Mac 앱) | ① 맞춤설정 → 스킬 → 만들기 ② 업로드하기(스킬 폴더·zip) 또는 수동으로 만들기 ③ 대화에서 `@스킬 이름`으로 부르기 | 개인 구글 계정 무료('26. 9. 30.~), 업무용 계정은 '27. 3.~ |
| **ChatGPT** | ① 플러그인 → 스킬 ② 추가 → 컴퓨터에서 업로드 ③ 받은 `.skill` 올리면 바로 사용 | Plus 요금제·Work 모드에서 **한글 파일까지 확인**('26. 11. 1.) |

※ 메뉴 이름은 앱 판에 따라 다를 수 있습니다('26. 11. 1. 화면으로 확인). 한글 파일을 만들어 주는 것은 Claude 앱과 ChatGPT에서 확인했습니다. 파일을 만들 수 없는 앱에서는 서식 원칙대로 쓴 글을 받아 한글에 붙여 넣으세요.

## 쓰는 법 — 대화창에 이렇게 말하면 됩니다

- (견본 .hwpx를 올리고) "이 양식대로 ○○ 추진계획(안) 한글 파일로 만들어 줘. 내용은 …"
- "견본 없이 기본 양식으로 ○○ 결과보고 만들어 줘. 표지도 넣어 줘."
- "사진 두 장은 표에 넣어 줘." (사진도 함께 올림)
- 내용이 거의 없으면 Claude가 근거법령부터 번호 선택지로 하나씩 물어봅니다.
- 옛 형식 `.hwp`는 읽지 못합니다. 한글에서 **[파일] → [다른 이름으로 저장] → 파일 형식 HWPX**로 저장해 올리세요.
- 결과 파일을 한글에서 고쳐 다시 올리면, 그 파일을 새 견본으로 삼아 다음 문서에 반영합니다.

## 저절로 해 주는 일

| 구분 | 하는 일 |
|---|---|
| 글 | 괄호 이름표 줄 맞춤(`(현  황)`·`(문제점)`), 작대기 항목명 세 글자 폭, 네 글자 제목 붙여 쓰기, 단어 단위 줄 바꿈, 쌍점·이름표 뒤 내어쓰기, 부연설명 괄호 2pt 작게, **\*·※ 설명글은 설명하는 글보다 1pt 작게**, 따옴표·낫표·가운데점 붙이기 |
| 쪽 | 마지막 줄에 한두 글자만 남으면 자간 줄이기, □ 묶음·○ 묶음을 한 쪽에, 줄 간격으로 쪽 맞춤, 참고 쪽 꽉 채우기 |
| 표 | 끝선 맞춤, 칸 너비·글자 크기(12→10pt) 맞춤, 금액은 오른쪽·나머지는 가운데 정렬, 기준·단위 줄, **표 밑 ※·\*는 표 글자보다 1pt 작게**, **사진은 표 칸 배경으로**(가로세로 비율 유지, 용량 줄임), 도표(`flow`)는 투명 선 표 |
| 짜임 | **근거법령은 늘 1번**(Ⅰ. 근거법령 또는 첫 □), 요약 상자는 한 문장, □ 아래 ○·○ 아래 -는 셋쯤(2~5개) — 벗어나면 알려 줌 |
| 표지 | 시 슬로건·제목 띠·개요 상자·대구시 마크·부서명, 표지는 쪽 번호 없이 본문부터 1쪽 |

## 꼭 알아 두세요

- **공개해도 되는 자료만 올리세요.** Claude·ChatGPT·Gemini에 올린 파일과 대화는 외부 서비스로 전송됩니다. 비공개 문서·개인정보(이름·연락처·주민번호)는 올리지 마세요. 업무망 보안 지침상 생성형 AI 사용이 제한되면 그 지침을 따르세요.
- 사실·숫자·법령은 **사용자가 준 것과 법령 검색으로 원문을 확인한 것만** 씁니다. 모르는 값은 `○○`로 비워 두고 알려 줍니다. 그래도 결과는 반드시 직접 확인하세요.
- 한글 프로그램 없이 줄·쪽을 어림해서 맞춥니다. 마지막 확인은 한글에서 열어 보세요.
- 표지의 슬로건·심벌은 대구광역시 것입니다.

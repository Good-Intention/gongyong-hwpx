# 공무원 한글문서 편집스킬 — 한글 보고서를 만들어 주는 AI 스킬

**부르는 이름(호출명): `/gongyong-hwpx`**

견본 한글 파일을 올리고 쓸 내용만 말하면, **그 양식 그대로 한글(.hwpx) 보고서**를 만들어 줍니다.

- 견본이 없으면 기본 보고서 양식(제목 상자·요약 상자·□○-·표·참고)으로 작성
- **이미 쓴 한글 파일은 '정돈'** — 글·문체·차례는 그대로 두고 줄 나눔·맞춤·간격만 손질(v2.0)
- 줄 끝·이름표 폭·표 칸 너비·쪽 나눔 등 서식 손질은 도구가 자동 처리 ⇒ 작성자는 내용 검토에 집중
- **대구시청 현직 공무원**이 보고서 서식 손질에 드는 시간을 줄이려고 직접 만들었습니다. 업무 현장에서 쓰는 서식 원칙을 그대로 담았습니다

| **Gemini** (웹·Mac 앱) | ① 맞춤설정 → 스킬 → 만들기 ② 업로드하기 ③ 대화에서 `@스킬 이름`으로 부르기 | 한글 파일 작성은 아직 확인 못 함(글로 받아 붙여 넣기) |

※ 메뉴 이름은 앱 판에 따라 다를 수 있음('26. 11. 1. 화면 기준)

## 쓰는 법 — 대화창에 이렇게 말하면 됩니다

- 대화창에 **`/gongyong-hwpx`**를 입력해 스킬을 부른 뒤 요청(한글 파일 이야기를 하면 저절로 불리기도 함)
- (견본 파일 첨부) "이 양식대로 ○○ 추진계획(안)을 2쪽으로 써 줘. 내용은 …"
- "견본 없이 기본 양식으로 ○○ 현안 보고서 1쪽, 참고로 추진 일정표를 붙여 줘."
- "사진 두 장은 표에 넣어 줘." (사진도 함께 첨부)
- 결과를 보고 "□ 추진계획에 예산 표를 넣고 1쪽에 맞춰 줘"처럼 고칠 점을 말하면 같은 양식으로 다시 작성
- 대책 보고·개선방안·주간업무 보고·의회 답변서·언론보도 대응 보고·보도자료도 같은 방법으로(종류에 맞는 차례로 작성)
- (이미 쓴 한글 파일 첨부) "이 파일 그대로 정돈해 줘" — **정돈**: 글·문체·차례·쪽 수는 그대로, 서식만 제자리에서 손질(원본은 두고 `○○_정돈.hwpx`로)
  - 낱말 가운데서 끊기던 줄 ⇒ 어절 단위로, 둘째 줄은 이름표·쌍점·머리 기호 뒤 첫 글자에 맞춤
  - 이름표 폭(`(현    황)`)·괄호와 쌍점 위아래 한 줄, 같은 ○ 줄끼리 글자 크기
  - 끝 줄에 두세 글자만 남으면 자간을 줄여 올리고, 못 올리면 윗줄 낱말을 함께 내려 윗줄을 꽉 채움
  - ○ 제목이 쪽 끝에 홀로 남지 않게, ○ 위 간격, 표 칸 글 세로 가운데
  - ○·- 뒤 빈칸은 한 칸(조판 부호 하나), 줄머리 빈칸은 문단 여백으로
  - PDF·그림 문서는 정돈하지 않음 ⇒ "이 PDF 내용 그대로 한글로 옮겨 써 줘"(옮겨 쓰기)
- (이미 쓴 한글 파일 첨부) "이 파일 서식 검사해 줘" — **검사만**: 파일은 바꾸지 않고 고칠 곳만 알려 줌(근거법령 자리·개수, 요약 상자, 항목 수, 줄·표 맞춤, 쪽 수 변화)

※ 옛 형식 `.hwp`는 읽지 못함 ⇒ 한글에서 [파일] → [다른 이름으로 저장] → 파일 형식 HWPX로 저장해 올리기

## 저절로 맞추는 서식

| 구분 | 내용 |
|---|---|
| 문단 | □○-· 기호·들여쓰기, 괄호 이름표 네 글자 폭(`(현  황)`), 작대기 항목명 세 글자 폭, 끝 줄 한두 글자 올리기, 줄 첫머리 낫표(「)는 반 칸 당겨 아랫줄과 끝선 맞춤, ○·- 뒤 빈칸은 조판 부호 한 칸(양쪽 정렬에도 둘째 줄 맞춤 그대로) |
| 글자 | 부연설명 괄호 2pt 작게, \*·※ 설명글은 설명하는 글보다 2pt 작게 하고 아래를 조금 띄움(표 밑 ※는 표 글자보다 1pt 작게) |
| 표 | 칸 너비·글자 크기(본문보다 3pt 작게 — 기본 11pt, 한 장에 넣을 때만 줄임), ■ 표 제목(표 글자보다 1pt 크게, 참고 자체가 표면 생략), 표 끝선, 금액·수량 숫자는 오른쪽 정렬(오른쪽 조금 띄움, 날짜·연번은 가운데), 기준·단위 줄, 사진은 칸 배경(비율 유지), '항목 : 내용' 줄은 쌍점 자리를 위아래로 맞춤, 표 밑 ○·※ 글은 표에 붙지 않게 띄움 |
| 쪽 | ○와 그 아래 내용은 한 쪽에, 참고 쪽은 한 장에 꽉 채움 |
| 짜임 | 근거법령은 늘 1번(첫 □는 □ 근거법령, 로마자 장이면 Ⅰ.)이고 법령 이름·조항만(부연설명 없이), 요약 상자는 한 문장 — 벗어나면 옮기거나 알려 줌 |

## 꼭 알아 두세요

- **공개해도 되는 자료만 입력** — AI 앱에 올린 파일·대화는 외부 서비스로 전송됨. 비공개 문서·개인정보 입력 금지, 기관 보안 지침이 있으면 그 지침을 따름
- **숫자·법령 조문·날짜는 작성자가 원문과 대조** — 모르는 값은 `○○`로 비워 두고 알려 줌
- **결재 전 한글에서 열어 확인** — 줄·쪽은 한글 없이 어림해 맞춘 것
- **여백** — 기본 양식은 A4, 본문 칸 사방 20mm(결과를 줄 때마다 그 문서의 여백을 알려 줌). 온나라 공문에 붙여 넣을 때는 온나라 [쪽] → [편집 용지]에서 왼쪽·오른쪽 여백을 20·20mm로 맞추기 ⇒ 줄 바꿈이 그대로 감(쪽 끝은 붙여 넣은 뒤 확인)
- 표지의 슬로건·마크는 대구광역시 것(아래 이용 조건 참고)

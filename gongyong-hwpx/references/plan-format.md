# 계획 파일(plan.json) 규칙

`build.py`가 읽는 파일. 결과 문서의 문단을 위에서부터 차례로 적는다. 블록 하나 = 문단(또는 표) 하나.

```json
{"title": "문서 제목(파일 속성, 없어도 됨)",
 "blocks": [ {블록}, {블록}, … ]}
```

`blocks` 목록만 있는 파일(`[ {블록}, … ]`)도 된다.

## 블록 항목

| 항목 | 뜻 | 예 |
|---|---|---|
| `like` (필수) | 모양을 빌려 올 견본 문단 번호(양식 지도의 `[번호]`) | `"like": 6` |
| `text` | 넣을 글. 견본 문단의 머리 기호·앞 빈칸은 도구가 붙인다 | `"text": "추진배경"` |
| `runs` | 조각마다 모양을 직접 고를 때 `[[글, 조각 번호], …]` — 머리 기호도 직접 적는다 | `[["  ○ ", 0], ["(현황)", 1], [" 내용", 2]]` |
| `table` | 표를 줄 목록으로 채운다(줄·칸 수 자유) | `[["구분","내용"],["가","나"]]` |
| `cells` | 표 모양은 그대로 두고 칸만 채운다. 열쇠는 `"줄,칸"`(0부터) | `{"0,0": "참고1", "0,2": "세부 현황"}` |
| `header_rows` | `table`의 머리 줄 수(기본: 견본 표가 2줄 이상이면 1) | `"header_rows": 2` |
| `keep_header` | `true`면 머리 줄은 견본 글 그대로, `table`에는 내용 줄만 | `"keep_header": true` |
| `body_like` | 내용 줄 모양으로 쓸 견본 표 줄 번호(기본: 머리 줄 다음 줄) | `"body_like": 1` |
| `last_like` | 마지막 내용 줄(합계 등)에 쓸 견본 표 줄 번호 | `"last_like": 3` |
| `cols` | `table`의 칸 수(보통 줄 길이로 저절로). 견본 표와 다르면 첫·끝·가운데 칸 모양을 복사해 늘이거나 줄임 | `"cols": 5` |
| `widths` | 칸 너비 비율(없으면 도구가 내용에 맞춰 나눔) | `"widths": [1, 3, 3]` |
| `title` | **표 제목**(본문 표에는 늘 — 없으면 '고쳐야 함'): 표 위 왼쪽 `■ 제목` 줄. 도표(`flow`)에서는 상자 위 `< 제목 >` | `"title": "세부사업별 예산 현황"` |
| `unit` | 표 위 기준·단위 줄(표 오른쪽 끝, 표 글자보다 2pt 작게) | `"unit": "(기준 : ’26.9월) (단위 : 백만원)"` |
| 칸 값 `{"image": "파일"}` | 그 칸의 **배경**을 그림으로(글자처럼 넣는 그림이 아님). 칸 높이는 비율대로. 경로는 계획 파일 폴더 기준 또는 절대. `"caption"`을 더하면 그림 위에 글 | `["동대구역", {"image": "사진1.jpg"}, "설명"]` |
| `flow` | **도표(단계·흐름)**: 상자 글 목록(`\n`이면 두 줄). 화살표 `arrow`(기본 `→`), 줄 수 `rows`(1·2) | `{"like": 14, "title": "○○○ 신청절차", "flow": ["견본 수집\n(’26. 11.)", "스킬 보완", "배포"]}` |
| `page_break` | `true`면 새 쪽에서 시작, `false`면 견본의 쪽 나눔을 끔 | `"page_break": true` |
| `marker` | `false`면 견본 문단의 머리 기호를 붙이지 않는다 | `"marker": false` |
| `note` | 메모(도구는 무시) | |

`text`·`runs`·`table`·`cells`가 하나도 없으면 견본 문단을 그대로 복사한다(빈 줄, 고정 문구).

## 글 적는 법

- 머리 기호: 견본 문단이 `  ○ `로 시작하면 `text`에는 내용만. 기호까지 써도 겹치지 않게 떼어 낸다. 견본 기호와 다른 기호로 시작하면(`- 내용`을 `○` 문단에) 견본 기호를 쓰고 알린다 — 대개 `like`를 잘못 고른 것.
- `**…**` 굵은 조각(견본 문단의 굵은 조각 모양 — 이름표 `**(대상)** …`), `^^…^^` 위 첨자 조각(낱말 뒤 `^^*^^`, 줄임말 뒤 원래 이름 `유가보조금^^유류세연동보조금^^`). 견본 문단에 그 모양 조각이 있어야 한다. 나머지 글은 견본 문단에서 가장 긴 보통 조각의 모양.
- 괄호 이름표 `(현황)`은 그냥 쓴다. 같은 묶음의 이름표 폭은 도구가 맞춘다.
- 특수 문자: `\n` 줄 바꿈(표 칸 안에서는 새 문단), `\t` 탭, `⎵` 고정폭 빈칸(한글 Alt+Space, **1/4 글자 폭**, 양쪽 정렬 때 늘어나지 않음), `⍽` 묶음 빈칸(줄이 여기서 바뀌지 않음).
- 밑줄·색 글씨처럼 견본 문단에 따로 있는 조각 모양은 `runs`로 조각 번호를 골라 쓴다.

## 표

- 표가 든 문단을 `like`로 고른다(양식 지도에 `표 N×M`). 칸이 하나인 표(제목 상자·요약 상자)는 `text`로 채운다.
- 제목 걸친 상자(기본 양식 16번)는 `cells`: `{"like": 16, "cells": {"0,1": "<관 련 법 령>", "2,0": ["첫 줄", "둘째 줄", "", "넷째 줄"]}}` — `0,1`이 위 선에 걸친 제목, `2,0`이 상자 안 글(목록 하나가 한 줄, 빈 글은 빈 줄).
- `table`: 첫 `header_rows`줄은 견본 머리 줄을 복사해 채우고, 나머지는 `body_like` 줄을 복사(줄 수 제한 없음). 줄마다 칸 수는 견본 줄의 칸 수 이하(모자란 칸은 빈칸), `null`이면 견본 글 그대로. 본문 줄에 세로로 합친 칸이 있으면 줄 수를 바꿀 수 없다 → `cells`.
- 칸 안 여러 줄(`"가\n나"`)은 줄마다 칸 안 견본 문단을 복사. **한 칸에 여러 내용은 `· ` 줄로**: `"· 내PC지킴이 미달 PC 조치\n· 교육 미이수자 관리"`(이름 열은 쉼표 한 줄). 줄이 `○`·`-` 기호로 시작하면 칸 안에서 같은 기호로 시작하는 견본 문단을 고른다.
- 그래프·사진 상자: 한 열 표 `{"like": 14, "cols": 1, "table": [["[그림 1] 제목"], [{"image": "파일"}]]}`. 사용자가 올린 사진은 올린 경로 그대로(Claude 앱 `/mnt/user-data/uploads/…`).
- 표지(기본 양식 19~23번) 개요 상자는 `text`에 줄마다 `□ 제목`·`○ **(이름표)** 내용`을 `\n`으로 잇는다(칸 안 견본 문단 둘 가운데 기호가 같은 것을 줄마다 고름). 표지 다음 제목 상자(0번)는 `page_break` 없이도 새 쪽.
- 테두리·바탕색은 견본 그대로. 칸 너비·표 폭·글자 크기·줄 바꿈은 도구가 맞춘다(auto-fit.md). 표 높이는 한글이 열 때 글에 맞춰 다시 잡는다. ■ 제목은 `title`로만 — `text`로 ■ 줄을 따로 쓰면 표와 한 몸이 안 된다.

## 문서 전체 옵션(맨 위에, 모두 기본 true — 끌 때만 false)

| 옵션 | 하는 일 |
|---|---|
| `join_titles` | 네 글자 제목·이름표 붙여 쓰기 |
| `space_blocks` | □·Ⅰ. 앞 빈 줄 |
| `number_items` | 번호 매기기(Ⅰ. 1. 가. ①) |
| `push_down` | 끝 줄 한두 낱말을 위 줄 낱말과 함께 내려 7~10자로(끄면 올리기만) |
| `basis_first` | 근거법령을 1번으로 |
| `align_labels` | 괄호 이름표 폭 맞추기 |
| `keep_groups` | □·○ 묶음을 한 쪽에(다음 문단과 함께) |
| `word_wrap` | 어절 단위 줄 바꿈 |
| `tighten_quotes` | 따옴표·낫표·가운데점 붙이기 |
| `pull_corner` | 줄 첫머리 낫표 반 칸 당기기 |
| `table_notes` | 표 뒤 ※를 표 끝선 ※ 모양으로 |
| `note_small` | *·※ 설명글 2pt 작게 + 아래 3pt |
| `paren_small` | 부연설명 괄호 작게(pt 수, 기본 2, 끄려면 0) |
| `colons` | 쌍점 앞뒤 한 칸·내어쓰기 |
| `label_hang` | 이름표 뒤 내어쓰기 |
| `keep_numbers` | 숫자 꾸밈말 묶음 빈칸 |
| `square_small` | □ 기호 2pt 작게 |
| `fit` | 표 맞춤·줄 맞춤·쪽 맞춤 전부 |

예: `{"title": "…", "fit": false, "blocks": [ … ]}`

## 자주 하는 실수

| 알림·오류 | 고치는 법 |
|---|---|
| `like N — 견본에 그 번호의 문단이 없습니다` | 양식 지도의 번호를 다시 본다 |
| `표가 아닌 문단입니다` | 표가 든 문단 번호를 고른다 |
| `칸이 여럿인 표입니다` | `text` 대신 `table`이나 `cells` |
| `굵은 조각이 없어 보통 글씨로` | 굵은 이름표가 있는 견본 문단을 고르거나 `**`를 뺀다 |
| `위 첨자 조각이 없어` | 위 첨자가 있는 견본 문단을 고르거나 `^^`를 뺀다 |
| `합친 칸이 있는 표는 칸 수를 바꿀 수 없습니다` | 칸 수를 견본 표에 맞추거나 합친 칸 없는 표를 고른다 |
| `글 아닌 것(…)은 빼고 글만 넣었습니다` | 견본 문단에 각주·누름틀·그림이 있었다는 뜻. 필요하면 한글에서 다시 넣도록 알린다 |

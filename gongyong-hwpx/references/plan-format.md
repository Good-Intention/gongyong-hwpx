# 계획 파일(plan.json) 규칙

`build.py`가 읽는 파일이다. 결과 문서의 문단을 위에서부터 차례로 적는다.

```json
{"title": "문서 제목(파일 속성에 들어감, 없어도 됨)",
 "blocks": [ {블록}, {블록}, … ]}
```

`blocks` 목록만 있는 파일(`[ {블록}, … ]`)도 된다.

## 문서 전체 옵션(맨 위에 둠, 모두 기본값 true — 끌 때만 false)

| 옵션 | 하는 일 |
|---|---|
| `join_titles` | □·Ⅰ. 제목과 괄호 이름표의 네 글자(두 글자 + 두 글자)를 붙여 씀(추진 배경 → 추진배경) |
| `space_blocks` | □·Ⅰ. 앞에 한 줄 빈 줄을 넣음(계획에 이미 있으면 그대로) |
| `number_items` | 견본의 번호 기호(Ⅰ. 1. 가. ①)를 차례로 매김. 글에 번호가 있으면 그것을 씀 |
| `push_down` | 자간으로 올리지 못한 끝 줄 한두 낱말을 위 줄 낱말과 함께 내려 끝 줄을 7~10자로(끄면 올리기만 하고 못 고친 곳은 알림) |
| `basis_first` | 근거법령을 1번으로: 로마자 장 문서는 근거 장을 Ⅰ.로, 아니면 근거 □·○를 맨 앞으로(표지 개요 상자도), 없으면 알림 |
| `align_labels` | 같은 묶음 ○·- 항목의 괄호 이름표 폭 맞추기((현  황)·(문제점)) |
| `keep_groups` | □는 바로 아래와, ○와 그 아래 -·\*·※·표는 한 쪽에(다음 문단과 함께) |
| `word_wrap` | 쓰는 문단 모양을 모두 어절(단어) 단위 줄 바꿈으로 |
| `tighten_quotes` | 한 글자 폭 따옴표·낫표·가운데점을 붙임(휴먼명조) — 닫는 ’ ”·」는 그 글자 -50%, 여는 ‘ “·「는 그 앞 글자를 좁힘(「 앞 빈칸은 -50%·그 앞 글자 -20%), 낱말 사이 ·ㆍ는 앞 글자와 점을 -25%씩 |
| `table_notes` | 표 바로 뒤 ※ 줄을 표 왼쪽 끝선에서 시작하는 ※ 모양(견본에서 왼쪽 여백 0인 ※ 문단, 기본 양식 17번)으로 바꿈 |
| `note_small` | 설명 문단을 설명하는 글(바로 위 □·○·- 문단)보다 작게 — \* 풀이 2pt(아래 3pt 띄움), ※ 참고 1pt. 표 바로 뒤 ※·\*는 표 글자보다 1pt 작게(`fit`) |
| `paren_small` | ○·- 항목 글 속 부연설명 괄호를 괄호째 몇 pt 작게(기본 2, 끄려면 0). 첫머리 이름표·(안)·(가칭)·요일·「」 안은 그대로 |
| `colons` | 쌍점 앞뒤 한 칸(`항목 : 내용`), 두 줄 이상이면 아랫줄을 쌍점 뒤 첫 글자에 맞춤 |
| `label_hang` | 괄호 이름표 뒤 내용이 두 줄 이상이면 아랫줄을 이름표 뒤 첫 글자에 맞춤(`○ (근  거) …`) |
| `keep_numbers` | 약·총·최대·최소 등과 뒤 숫자 사이를 묶음 빈칸으로(`약 900대`가 갈라지지 않게) |
| `fit` | 표 끝선·칸 너비·숫자 칸, 마지막 짧은 줄 자간, 쪽 맞춤(빈 줄·줄 간격), 블록째 넘겨 빈 쪽 줄 간격 늘리기 |

예: `{"title": "…", "fit": false, "blocks": [ … ]}`

## 블록 항목

| 항목 | 뜻 | 예 |
|---|---|---|
| `like` (필수) | 모양을 빌려 올 견본 문단 번호(양식 지도의 `[번호]`) | `"like": 6` |
| `text` | 넣을 글. 견본 문단의 머리 기호·앞 빈칸을 도구가 붙인다 | `"text": "추진배경"` |
| `runs` | 조각마다 모양을 직접 고를 때. `[[글, 조각 번호], …]` — 머리 기호도 직접 적는다 | `[["  ○ ", 0], ["(현황)", 1], [" 내용", 2]]` |
| `table` | 표를 줄 목록으로 채운다(줄 수를 늘리거나 줄임) | `[["구분","내용"],["가","나"]]` |
| `cells` | 표 모양은 그대로 두고 칸만 채운다. 열쇠는 `"줄,칸"`(0부터) | `{"0,0": "참고1", "0,2": "세부 현황"}` |
| `header_rows` | `table`에서 머리 줄 수. 기본: 견본 표가 2줄 이상이면 1 | `"header_rows": 2` |
| `keep_header` | `true`면 머리 줄은 견본 글 그대로 두고 `table`에는 내용 줄만 적는다 | `"keep_header": true` |
| `body_like` | 내용 줄 모양으로 쓸 견본 표 줄 번호. 기본: 머리 줄 바로 다음 줄 | `"body_like": 1` |
| `last_like` | 마지막 내용 줄(합계 등)에 쓸 견본 표 줄 번호 | `"last_like": 3` |
| `cols` | `table`의 칸 수(보통 줄 길이로 저절로 정함). 견본 표와 다르면 첫·끝·가운데 칸 모양을 복사해 늘이거나 줄임 | `"cols": 5` |
| `widths` | 칸 너비 비율(없으면 내용에 맞춰 도구가 나눔) | `"widths": [1, 3, 3]` |
| 칸 값 `{"image": "그림 파일"}` | 그 칸의 **배경**을 그림으로 채움(글자처럼 넣는 그림이 아님). 칸 높이를 칸 너비 × 그림 비율로 맞춰 가로세로 비율을 지킴. 경로는 계획 파일 폴더 기준 또는 절대 경로. `"caption"`을 더하면 그림 위에 글 | `["동대구역", {"image": "사진1.jpg"}, "설명"]` |
| `flow` | **도표(단계·흐름)**: 표 선은 모두 투명, 상자 칸만 실선, 상자 사이 칸에 화살표(`arrow`, 기본 `→`). 그림 도형 대신 쓰는 방식(한글에서 바로 고침). 상자 글에 `\n`이면 두 줄. `title`은 도표 위 제목(굵게 가운데, 도구가 `< 제목 >`으로 감쌈 — 달아 둠). 상자는 가로로 긴 모양(높이 14mm, 글 3줄이면 19mm), 너비는 상자 수대로 나눠 42mm까지(42mm에 걸리면 가운데, 아니면 본문 폭에 꽉 채움). 여섯 이상이거나 한 줄이면 상자가 좁아 글이 넘치면 두 줄 — 둘째 줄도 왼쪽 → 오른쪽, 아래 화살표 없이 둘째 줄 첫 상자 앞에 →(그 왼쪽 끝 = 윗줄 첫 상자 왼쪽 선, 둘째 줄은 → 폭만큼 들어감)(`rows`로 1·2를 정할 수 있음) | `{"like": 14, "title": "○○○ 신청절차", "flow": ["견본 수집\n(’26. 11.)", "스킬 보완", "배포"]}` |
| `unit` | 표 위 기준·단위 줄(표 오른쪽 끝, 표 글자보다 2pt 작게 — 견본의 `(기준 : …)` 줄 모양, 기본 양식 18번) | `"unit": "(기준 : ’26.9월) (단위 : 백만원)"` |
| `page_break` | `true`면 새 쪽에서 시작, `false`면 견본의 쪽 나눔을 끔 | `"page_break": true` |
| `marker` | `false`면 견본 문단의 머리 기호를 붙이지 않는다 | `"marker": false` |
| `note` | 메모(도구는 무시). 왜 이 `like`를 골랐는지 적어 둘 때 | |

`text`·`runs`·`table`·`cells`가 하나도 없으면 견본 문단을 그대로 복사한다(빈 줄, 고정 문구 등).

## 글 쓰는 법

- 항목 수: □ 아래 ○, ○ 아래 -, - 아래 ·는 셋쯤(2~5개). 하나뿐이거나 다섯을 넘으면 도구가 알린다. 작대기(-) 다음 단계는 가운데점(·, 기본 양식 24번).
- 머리 기호: 견본 문단이 `  ○ `로 시작하면 `text`에는 내용만 쓴다. 기호까지 써도(`○ 내용`) 겹치지 않게 떼어 낸다.
  - 견본 기호와 다른 기호로 시작하면(`- 내용`을 `○` 문단에) 견본 기호를 쓰고 알림을 낸다. 대개 `like`를 잘못 고른 것이다.
- 굵은 조각: `**…**`로 감싼 부분은 견본 문단의 굵은 조각 모양을 쓴다.
  - 예: 견본 `  ○ (현황) 내용`의 `(현황)`이 굵게면 `"text": "**(대상)** 관내 공원 120곳"`.
- 위 첨자: `^^…^^`로 감싼 부분은 견본 문단의 위 첨자 조각 모양을 쓴다. 설명을 다는 낱말 뒤 `*`에 쓴다.
  - 예: `"text": "노후 시설이 29곳^^*^^으로 …"` 다음 블록에 `*` 설명 문단(기본 양식 8·11번).
  - 줄임말 바로 뒤 원래 이름도 위 첨자로 붙인다(괄호 없이): `"text": "유가보조금^^유류세연동보조금^^ 지급 기준 정비"`.
- 나머지 글은 견본 문단에서 가장 긴 보통 조각의 모양을 쓴다.
- 괄호 이름표 `(현황)`은 그냥 쓰면 된다. 같은 묶음의 이름표 폭은 도구가 맞춘다(`align_labels`).
- 특수 문자:
  - `\n` 줄 바꿈(표 칸 안에서는 새 문단), `\t` 탭
  - `⎵` 고정폭 빈칸(한글의 Alt+Space, **1/4 글자 폭**, 양쪽 정렬 때 늘어나지 않음), `⍽` 묶음 빈칸(줄이 여기서 바뀌지 않음)
- 위첨자·밑줄·색 글씨처럼 견본 문단에 따로 있는 조각 모양은 `runs`로 그 조각 번호를 골라 쓴다.

## 표

- 표가 든 문단을 `like`로 고른다(양식 지도에 `표 N×M`이 보이는 문단).
- 칸이 하나인 표(제목 상자·요약 상자)는 `text`로 채울 수 있다.
- 제목 걸친 상자(기본 양식 16번)는 `cells`로 채운다: `{"like": 16, "cells": {"0,1": "<관 련 법 령>", "2,0": ["첫 줄", "둘째 줄", "", "넷째 줄"]}}` — `0,1`이 위 선에 걸친 제목, `2,0`이 상자 안 글(목록 하나가 한 줄, 빈 글은 빈 줄).
- `table` 방식:
  - 첫 `header_rows`줄은 견본 표의 머리 줄을 하나씩 복사해 채운다.
  - 나머지 줄은 모두 `body_like` 줄을 복사해 채운다. 줄 수에 제한이 없다.
  - 줄마다 칸 수는 견본 줄의 칸 수와 같거나 적어야 한다(모자란 칸은 빈칸).
  - 칸 값을 `null`로 두면 견본 글을 그대로 둔다.
  - 본문 줄에 세로로 합친 칸이 있으면 줄 수를 바꿀 수 없다 → `cells`를 쓴다.
- 칸 안에 여러 줄을 넣으면(`"가\n나"`) 줄마다 칸 안 견본 문단을 복사한다.
  - **한 칸에 여러 내용**은 쉼표로 잇지 말고 `· ` 줄로 나눈다: `"· 내PC지킴이 미달 PC 조치\n· 교육 미이수자 관리"` — 도구가 왼쪽 정렬·왼쪽 1.5mm 띄움·둘째 줄을 기호 뒤 글에 맞춘다(사용자 원칙 2026-11-01).
  - 칸보다 긴 낱말은 한글이 글자 단위로 끊는다. 가운데점으로 이은 이름(`대구정책연구원·성과평가위원회`)은 도구가 점 뒤에서 줄을 나누고, 그 밖의 긴 이름은 띄어 쓸 수 있으면 띄운다(`기관공유데이터 관리시스템` — 도구가 알림).
  - 줄이 `○`·`-` 같은 기호로 시작하면 칸 안에서 같은 기호로 시작하는 견본 문단을 골라 쓴다.
- 테두리·바탕색은 견본 그대로다. 칸 너비는 칸 글이 줄을 넘지 않게 도구가 나누고(`widths`로 직접 정할 수 있음), 표 폭은 본문 폭에 맞춘다(끝선 맞추기). 표 높이는 한글이 열 때 글에 맞춰 다시 잡는다.
- 표 글자 크기는 도구가 견본 크기(기본 양식 12pt)에서 10pt까지 줄여 다음 줄로 넘어가는 줄이 가장 적은 크기를 고른다. 10% 안에서 넘치는 칸 글은 '한 줄로 입력', 두 줄 이상인 칸 글은 윗줄·아랫줄이 고르게 줄 바꿈을 넣는다(계획에 `
`을 넣으면 그 자리는 그대로). 시기 기준·금액 단위는 `unit`으로 표 위에 둔다.
- 표지(기본 양식 19~23번)의 개요 상자는 `text`에 줄마다 `□ 제목`·`○ **(이름표)** 내용`을 `
`으로 잇는다 — 칸 안 견본 문단 둘(□·○) 가운데 기호가 같은 것을 줄마다 고른다. 표지 다음 제목 상자(0번)는 `page_break`를 쓰지 않아도 새 쪽에서 시작한다.
- 참고 쪽(참고 머리표부터 끝)은 도구가 표 줄 높이를 맞춰 가급적 한 장에 꽉 채우고, 작은 표는 앞 덩어리와 한 장에 모은다(이때 계획의 `page_break`도 뺄 수 있음).
- **표 안 그림은 셀 배경으로**(사용자 원칙 2026-11-01): 칸 값에 `{"image": "파일"}`. 도구가 그림을 긴 변 1,200화소로 줄이고 흰 바탕에 합쳐 JPEG·PNG 가운데 작은 쪽으로 넣는다(사진은 대개 JPEG, 로고·도표는 PNG — 8MB 사진이 약 200KB). Pillow가 없으면 원본 그대로 넣고 알린다. 한 줄에 그림이 둘 이상이면 글 칸은 두고 남은 폭을 그림 비율대로 나눠 **높이가 같게**, 줄 높이는 그림 비율대로(그 줄은 쪽 채우기로 늘리지 않음). 비율이 5% 넘게 어긋나면 알린다. PNG·JPEG만.
- 칸 너비는 칸 안 여백(보통 좌우 3.6mm)보다 1mm 이상 넓어야 한다. 좁으면 한글이 저절로 넓혀 표가 튀어나온다(검사 결과에 '좁은 칸'으로 알림).

## 자주 하는 실수

| 알림·오류 | 고치는 법 |
|---|---|
| `like N — 견본에 그 번호의 문단이 없습니다` | 양식 지도의 번호를 다시 본다 |
| `표가 아닌 문단입니다` | 표가 든 문단 번호를 고른다 |
| `칸이 여럿인 표입니다` | `text` 대신 `table`이나 `cells`를 쓴다 |
| `굵은 조각이 없어 보통 글씨로` | 굵은 이름표가 있는 견본 문단을 `like`로 고르거나 `**`를 뺀다 |
| `위 첨자 조각이 없어` | 위 첨자 *가 있는 견본 문단을 고르거나 `^^`를 뺀다 |
| `합친 칸이 있는 표는 칸 수를 바꿀 수 없습니다` | 칸 수를 견본 표에 맞추거나 합친 칸이 없는 표를 고른다 |
| `글 아닌 것(…)은 빼고 글만 넣었습니다` | 견본 문단에 각주·누름틀·그림이 있었다는 뜻. 필요하면 한글에서 다시 넣도록 알린다 |

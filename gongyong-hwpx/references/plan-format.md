# 계획 파일(plan.json) 규칙

> 한 주제 = 한 파일 한 곳 — 이 파일은 계획 파일 문법만.

`build.py`가 읽는 파일. 결과 문서의 문단을 위에서부터 차례로 적는다. 블록 하나 = 문단(또는 표) 하나.

```json
{"title": "문서 제목(파일 속성, 없어도 됨)",
 "blocks": [ {블록}, {블록}, … ]}
```

`blocks` 목록만 있는 파일(`[ {블록}, … ]`)도 된다.

## 블록 항목

| 항목 | 뜻 | 예 |
|---|---|---|
| `like` (필수) | 모양을 빌려 올 견본 문단 번호(양식 지도의 `[번호]`) | `"like": 6` |
| `text` | 넣을 글. 견본 문단의 머리 기호·앞 빈칸은 도구가 붙인다 | `"text": "추진배경"` |
| `table` | 표를 줄 목록으로 채운다(줄·칸 수 자유) | `[["구분","내용"],["가","나"]]` |
| `cells` | 표 모양은 그대로 두고 칸만 채운다. 열쇠는 `"줄,칸"`(0부터) | `{"0,0": "참고1", "0,2": "세부 현황"}` |
| `title` | **표 제목**(본문 표에는 늘 — 없으면 '고쳐야 함'): 표 위 왼쪽 `■ 제목` 줄. 도표에서는 상자 위 `< 제목 >` | `"title": "세부사업별 예산 현황"` |
| `unit` | 표 위 기준·단위 줄(표 오른쪽 끝, 표 글자보다 2pt 작게) | `"unit": "(기준 : ’26.9월) (단위 : 백만원)"` |
| `page_break` | `true`면 새 쪽에서 시작, `false`면 견본의 쪽 나눔을 끔 | `"page_break": true` |
| `note` | 메모(도구는 무시) | |

`text`·`runs`·`table`·`cells`가 하나도 없으면 견본 문단을 그대로 복사한다(빈 줄, 고정 문구).

## 글 적는 법

- 머리 기호: 견본 문단이 ` ○ `로 시작하면 `text`에는 내용만. 기호까지 써도 겹치지 않게 떼어 낸다. 견본 기호와 다른 기호로 시작하면(`- 내용`을 `○` 문단에) 견본 기호를 쓰고 알린다 — 대개 `like`를 잘못 고른 것. 머리 기호가 없는 견본 문단(제목 상자 `○○○ 추진계획(안)`처럼 같은 기호가 잇달아 오는 자리표시 포함)에는 `1. 업무용 차량 운영` 같은 번호 제목을 그대로 쓰면 된다.
- 빈칸: 보통 빈칸을 쓴다(U+00A0은 옛 글꼴에서 네모로 보여 도구가 묶음 빈칸 `⍽`으로 바꿈).
- `**…**` 굵은 조각(견본 문단의 굵은 조각 모양 — 이름표 `**(대상)** …`), `^^…^^` 위 첨자 조각(낱말 뒤 `^^*^^`, 줄임말 뒤 원래 이름 `유가보조금^^유류세연동보조금^^`). 견본 문단에 그 모양 조각이 있어야 한다. 나머지 글은 견본 문단에서 가장 긴 보통 조각의 모양.
- 괄호 이름표 `(현황)`은 그냥 쓴다. 같은 묶음의 이름표 폭은 도구가 맞춘다.
- 특수 문자: `\n` 줄 바꿈(표 칸 안에서는 새 문단), `\t` 탭, `⎵` 고정폭 빈칸(한글 Alt+Space, **1/4 글자 폭**, 양쪽 정렬 때 늘어나지 않음), `⍽` 묶음 빈칸(줄이 여기서 바뀌지 않음).

## 표

- 표가 든 문단을 `like`로 고른다(양식 지도에 `표 N×M`). 칸이 하나인 표(제목 상자·요약 상자)는 `text`로 채운다.
- `table`: 머리 줄은 견본 머리 줄을, 나머지는 견본 내용 줄을 복사해 채운다(줄 수 제한 없음). 줄마다 칸 수는 견본 줄의 칸 수 이하(모자란 칸은 빈칸), `null`이면 견본 글 그대로. 본문 줄에 세로로 합친 칸이 있으면 줄 수를 바꿀 수 없다 → `cells`.
- 칸 안 여러 줄(`"가\n나"`)은 줄마다 칸 안 견본 문단을 복사. **한 칸에 여러 내용은 `· ` 줄로**: `"· 내PC지킴이 미달 PC 조치\n· 교육 미이수자 관리"`(이름 열은 쉼표 한 줄). 줄이 `○`·`-` 기호로 시작하면 칸 안에서 같은 기호로 시작하는 견본 문단을 고른다.
- 테두리·바탕색은 견본 그대로. 칸 너비·표 폭·글자 크기·줄 바꿈·표 높이는 도구·한글이 맞춘다. ■ 제목은 `title`로만 — `text`로 ■ 줄을 따로 쓰면 표와 한 몸이 안 된다.

## 문서 전체 옵션(맨 위에)

| 옵션 | 하는 일 |
|---|---|
| `doc_type` | (글) 근거법령 없이 시작하는 종류면 그 이름 — `회의자료`·`보도자료`·`의회 답변서`·`주간업무 보고`·`사업설명서`·`언론보도 대응 보고`(검사만은 `--doc-type`) |
| `basis_searched` | (참·거짓, 기본 거짓) 근거법령 ○가 하나뿐이고 둘째 근거를 찾아봤지만 없으면 `true`(검사만은 `--basis-searched`) |
| `basis_first` | (기본 true) 근거법령을 1번으로 — 끄면 근거법령 검사도 건너뜀 |
| `omit` | (목록) 사용자가 일부러 뺀 요소 — `date`(날짜·부서 줄)·`summary`(요약 상자)·`basis`(근거법령)·`table_title`(■ 표 제목). 그 요소의 '고쳐야 함'이 알림으로(검사만은 `--omit`) |
| `fit` | (기본 true) 표 맞춤·줄 맞춤·쪽 맞춤 전부 |
| `body_pt` | (숫자, 기본 14) 표 글자의 기준인 본문 크기 — 표 글자는 이보다 3pt 작게. 사용자가 본문 크기를 따로 말했을 때만 넣는다 |

예: `{"title": "…", "fit": false, "blocks": [ … ]}`. 나머지 옵션은 모두 기본값이 참이라 보통 건드리지 않는다.

# 검사만 — 이미 쓴 문서를 바꾸지 않고 살피기

> 사용자가 이미 쓴 한글 파일을 주며 검사를 바랄 때 읽는다.

사용자가 **이미 쓴 한글 파일**을 주며 "검사해 줘", "서식 봐 줘", "원칙에 맞는지 봐 줘"라고 하면(새로 쓰라는 말이 없으면) 다시 만들지 말고 **검사만** 한다 — 파일을 바꾸지 않는다.

```bash
python scripts/review.py 문서.hwpx        # 표가 많아 느리면 --no-tables
# 사용자가 일부러 뺀 요소가 있으면 --omit date,summary(계획의 "omit"과 같음 — 이 스킬로 만든 문서는 표시가 남아 저절로)
```

- 결과를 그대로 옮긴다: 어림 쪽 수·여백 → **고쳐야 함**(글·짜임 — 작성자가 정할 것) → **정돈이 고칠 것**(정돈을 저장 없이 돌려 실제로 바뀌는 문단 그대로. 이 도구로 만든 문서는 거의 '없음') → 참고(쓰인 글꼴).
- 고쳐 달라고 하면: 글·짜임은 사용자가 정한 대로 계획 파일을 새로 써서 만들고(견본 = 그 파일), 서식만 고치려면 정돈 모드(SKILL.md 0절)로 한다.
- 견본과 다른 짜임(□○ 없는 서술식 등)은 알림이 비거나 어긋날 수 있다.

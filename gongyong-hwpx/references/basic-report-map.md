# 기본 보고서 양식(assets/basic_report.hwpx) 번호표

> 한 주제 = 한 파일 한 곳 — 이 파일은 기본 양식 번호표만. 계획을 기호로 쓰면(plan-format) 볼 일이 없다 — 조문 상자(16)·표지(19~23)처럼 **번호로 골라야 하는 문단**을 쓸 때만 읽는다.

- 용지 A4 세로, 여백 왼쪽·오른쪽 20mm, 위·아래 10mm, 머리말·꼬리말 10mm → 본문 폭 170mm, 높이 257mm. 아래 가운데 쪽 번호 `- 1 -`. 머리말 오른쪽 위에 시 슬로건 띠 그림(높이 9mm, 투명 바탕 — 표지 쪽은 감춤, 계획에 쓸 것 없음). 줄 나눔은 어절 단위. 줄 간격은 본문 160%·□ 제목 170%.
- 한 줄 길이: 제목 상자 약 23자, 요약 상자 약 32자, ○ 약 32자, - 약 33자.

# 양식 칸 채우기 — 표 안 보고서(신청서·안내서 양식의 표 칸에 글 넣기)

사용자가 **칸을 채우는 양식 파일**(참가신청서·구동안내서 등)을 주며 "이 칸에 써 줘"라고 할 때. **표 안 보고서**는 표(흔히 `구분 | 내용` 2열)의 넓은 칸 안에 □·○·- 글과 작은 표·그림을 넣어 쪽을 넘겨 가며 쓰는 문서다. 양식의 표·칸은 그대로 두고 칸 글만 넣는다. 보고서 원칙(근거법령 1번·요약 상자 등)은 적용하지 않는다.

```
python scripts/form_fill.py 양식.hwpx --list            # 1. 문단·표·칸 번호 보기
python scripts/form_fill.py 양식.hwpx --plan 계획.json --out 결과.hwpx --max-pages 5   # 2. 채우고 정돈(쪽 상한은 양식에 있을 때만)
```

```json
{"keep": [12, 18], "drop": [15], "pt": 10, "line": 125,
 "cells": [{"para": 14, "row": 1, "col": 1, "lines": [
              "□ **제목**", "○ **이름표** : 내용", "- 세부", "※ 설명",
              {"table": [["구분", "값"], ["가", "1"]], "widths": [3, 1]},
              {"images": [{"image": "a.png", "caption": "설명"}, {"image": "b.png", "caption": "설명"}], "cols": 2}]},
           {"para": 14, "row": 0, "col": 1, "text": "짧은 글"},
           {"para": 14, "row": 2, "col": 1, "text": ""}]}
```

- `keep`: 한 파일에 여러 양식이 있으면 쓸 양식의 처음·끝 문단 번호(안내용 표에 같은 양식 이름이 또 나오니 `--list`로 고른다). `drop`: 그 안에서 뺄 문단(안내문). 구역이 여럿인 파일은 첫 구역만 채우고, `keep`을 주면 뒤 구역을 뺀다(없으면 그대로 둠).
- `lines`: 보고글 — 양쪽 정렬·검정 글자로 넣고, 내어쓰기·들임·간격·끝 줄·끝선은 정돈이 맞춘다. □ 제목과 ○ 이름표는 `**굵게**`. ※ 줄은 1pt 작게 들어간다. `text`: 칸의 정렬을 그대로 둔 짧은 글(이름·날짜, `""`이면 안내문 지우기). 합친 칸은 왼쪽 위 칸 번호로.
- `pt`·`line`(계획 전체 또는 칸마다): 보고글 글자 크기·줄 간격. 칸 글이 많은 양식은 10pt·125~130%(사용자 견본). `line`이 없으면 양식 값, 130%보다 넓으면 130%.
- `table`(`lines` 안): 칸 안 표 — 칸 폭에 맞추고 글자는 보고글보다 1pt 작게, 첫 줄은 회색 머리 줄(`"head": false`면 없음), 줄 높이는 글 줄 수에 맞춘다. `widths`는 칸 비율(없으면 글 길이로), `align`은 칸별 정렬(없으면 짧은 말·숫자 열은 가운데).
- `images`(`lines` 안): 칸 안 그림 — `cols`개씩 작은 표(그림 + 설명)로 나눠 쪽을 넘길 수 있게 하고, 칸 배경으로 넣는다. 같은 줄 그림은 칸 비율에 맞춰 흰 여백을 붙인다(자르지 않음). `cols`는 1~6, `height_mm`(그림 높이 상한)는 10~250. 그림은 계획 파일 기준 경로 또는 전체 경로.
- `lines`를 넣은 표의 첫 줄이 짧은 머리 줄(구분·내용)이면 쪽마다 반복한다(끄려면 `"repeat_head": false`).
- 안내문의 파란 기울임 글자는 쓰지 않고 검정 보통 글자로 복제한다. 쪽 설정은 남긴 첫 문단으로 옮기고 모아찍기는 끈다.
- 칸 너비(`"widths_mm": {"14": [27, 143]}`, 칸마다 3mm 이상)는 양식을 바꾸는 일이라 사용자가 허락할 때만.
- 좁은 칸의 전화·이메일이 글자 단위로 끊기면 `text`에 `\n`을 넣어 두 줄로.

## 건네기 전

1. `## 쪽`과 `## 쪽 상한`을 전한다. '아래가 크게 빈 쪽'이 나오면 칸 안 표·그림 차례를 바꾸거나 작게 한다.
2. 쪽은 어림이다. 쪽 상한이 있는 양식은 **한글에서 PDF로 저장해 쪽 수를 확인**하시라고 알린다(쪽 그림은 모아찍기를 보여 주지 않음).
3. 칸 안 표와 그림은 글자처럼 취급되어 쪽 끝에서 통째로 다음 쪽으로 밀린다 — 쪽 끝이 비면 ○ 차례를 바꾸거나 그림을 줄인다. 쪽을 넘는 칸의 왼쪽 제목(구분 칸)은 첫 조각에만 나온다(한글 동작).

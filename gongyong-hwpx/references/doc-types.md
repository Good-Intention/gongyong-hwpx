# 문서 종류별 차례

> 한 주제 = 한 파일 한 곳 — 이 파일은 문서 종류별 차례·자주 쓰는 표만. 쓰려는 종류 한 행만 읽는다. 사용자가 차례를 주면 그대로 따른다.

목차: 여러 쪽 계획(안) · 한 쪽 보고(현안 보고) · 결과보고(행사·사업·출장) · 검토보고(요청·질의·제안) · 회의자료 · 문제해결·대책 보고 · 개선방안 · 제도도입 · 연례계획 · 종합계획 · 사업설명서 · 언론보도 대응 보고 · 보도자료 · 의회 답변서 · 주간업무 보고 · 자주 쓰는 표(시간계획표·1안·2안 비교표)

여러 쪽 계획(안)·추진계획의 기본 차례(로마자 장은 본문이 4쪽 이상인 긴 계획서에서만 — 그보다 짧으면 같은 차례를 로마자 장 없이 □로):

| 차례 | 내용 |
|---|---|
| 제목 | `○○○ ○○ 추진계획(안)` — 부서명·연도·사업명·문서 종류 |
| 요약 | 결론 한 문장 두세 줄 |
| Ⅰ. 근거법령 | □ 없이 ○로 법령·규칙·계획 하나씩(상위법 먼저) |
| Ⅱ. 개요 | □ 평가개요·사업개요: (기간)·(대상)·(결과활용) + 기본 표 |
| Ⅲ. 현황 진단 | 표: 구분 \| 현황 \| 위험 요인 \| 판단(굵게 **최우선.** **보강 대상.** **방어.**) |
| Ⅳ. 추진계획 | 항목별 할 일 — `할 일(담당팀) — ’26. 12. 18.(금)까지` |
| Ⅴ. (연계·기대 효과 등) | 필요한 장만 |
| Ⅵ. 추진일정 및 행정사항 | 주차별 표(주차 \| 기간 \| 주요 할 일) + 행정사항 |
| 참고1 | 근거법령 조문 발췌(참고 머리표 제목은 `근거법령`) |
| 참고2~n | 세부 표·확인 요청 사항(연번 \| 확인 사항 \| 확인처 \| 이유) |

| 종류 | 차례(□) |
|---|---|
| 한 쪽 보고(현안 보고) | 제목 상자 → 날짜·부서 → 요약 상자 → □ 2~4개(첫 □는 근거법령) → (참고) |
| 결과보고(행사·사업·출장) | 근거법령 → 추진개요(일시·장소·대상·내용) → 추진결과(실적·성과 표) → 평가·문제점 → 향후계획(보완·확산) → 참고(사진·명단). 결과 숫자는 사용자가 준 것만 |
| 검토보고(요청·질의·제안) | 근거법령 → 검토배경(요청 내용·경위) → 검토내용(현황·쟁점 — 비교표) → 검토의견(⇒ 결론, 대안은 1안·2안 비교표) → 조치계획(일정·담당). 의견은 근거 조문과 함께 |
| 회의자료 | 회의개요(일시·장소·참석·안건) → 안건별 내용(□마다 ○ 현황 → ○ 논의사항 → ○ 결정 필요 사항) → 행정사항. 참석자는 직위·부서까지. 시간계획표를 씀 |
| 문제해결·대책 보고 | 근거법령 → 현황 → 문제점 → 대책(규정에 맞는지 근거 조문과 함께) → 향후계획 |
| 개선방안 | 근거법령 → 추진배경 → 운영실태 → 문제점 → 다른 기관 사례(비교표) → 개선방안 → 추진일정 |
| 제도도입 | 근거법령 → 도입 필요성 → 현황·해결과제 → 사례 → 도입방안 → 기대효과 → 행정사항 |
| 연례계획 | 근거법령 → 지난해 성과 분석 → 보완할 점 → 추진방향 → 추진과제 → 추진일정 |
| 종합계획 | 근거법령 → 추진배경 → 여건 분석 → 비전·목표·과제(표) → 실행계획 → 부서별 역할 |
| 사업설명서 | 예산현황 → 예산편성 사유 → 사업개요(사업기간·사업비·사업내용·시행주체) → 미반영시 문제점. 줄 순서: 사업기간 → 사업비(괄호 재원) → 사업규모·내용 → 시행주체 → 추진실적·계획 → 사업근거 |
| 언론보도 대응 보고 | 제목 `○○ 보도 관련 대응 보고` → 보도 요지(매체·날짜·면, 기사 제목, 주요 내용 ○ 두세 개) → 사실 확인(맞는 것·다른 것을 ○로 나눔, 다른 것은 실제 수치·근거와 함께) → 조치계획(정정보도 요청·해명자료·후속 조치, 날짜) |
| 보도자료 | 제목(핵심 한 줄) → 부제(`- … -`) → 첫 문단에 누가·언제·무엇을 → 본문 □ 두세 개 → 붙임(사진·표). 두괄식, 쉬운 말. **서술식(‘~한다’, ‘~했다’)이라 개조식 원칙의 예외** — 견본이 있으면 견본 문체 |
| 의회 답변서 | 질문 요지(한 줄) → ○ 답(현황·원인) → - `다만,` 보충 → ○ 향후 계획·노력 |
| 주간업무 보고 | `<추진실적>` ○ 한 일(날짜) / `<추진계획>` □ 과제 → ○ 할 일. 날짜는 줄 끝 괄호 `(11. 20.)`, 기간 `(11. 18.∼11. 22.)` |

말씀자료(축사·인사말)는 연설문이라 이 스킬로 쓰지 않는다(글만 써 줌).

**자주 쓰는 표**(기본 양식 표 하나로 줄·칸 수만 바꿔 씀, 표 위에 ■ 제목·아래 ※ 단서):
- 행사·회의 시간계획표: `["시  간","소요","진행 내용","담  당"]`, 시간 `14:00∼14:10`, 소요 `10′`, 담당은 직위·팀까지(이름 없음), 끝에 `폐회` 줄. 보기: `"■ 행사 진행 순서"`, `{"table": [["시  간","소요","진행 내용","담  당"], ["14:00∼14:10","10′","개회·인사 말씀","○○○○과장"]]}`
- 1안·2안 비교표: `["구  분","1안 ○○","2안 ○○"]`, 줄은 `소요 예산` | `장  점` | `단  점` | `검토의견`. 장단점은 칸 안 `· ` 줄 두세 개, 검토의견 줄에 `채택(주민 참석 쉬움)`처럼 한 말로. 보기: `"■ 장소 대안 비교"`, `{"table": [["구  분","1안 ○○","2안 ○○"], ["장  점","· 비용 없음\n· 장비 바로 활용","· 접근 쉬움\n· 참석 쉬움"], ["검토의견","제외(○○)","채택(○○)"]]}`

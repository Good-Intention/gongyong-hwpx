# 계획 파일 — 덜 쓰는 항목

> 한 주제 = 한 파일 한 곳 — 이 파일은 계획 파일의 덜 쓰는 항목만. 조각 모양을 직접 고르거나, 견본 표의 줄·칸·너비를 정하거나, 머리 기호·자동 처리를 끌 때만 읽는다.

## 블록 항목(번호 꼴 `{"like": 번호, …}` 블록에)

| 항목 | 뜻 | 예 |
|---|---|---|
| `title` · `unit` | 표 블록의 ■ 제목·기준·단위 줄(기호 꼴에서는 표 앞에 `■ 제목` 줄로 써도 같음). 도표(`flow`)에서는 상자 위 `< 제목 >` | `"title": "세부사업별 예산 현황"` |
| `runs` | 조각마다 모양을 직접 고를 때 `[[글, 조각 번호], …]` — 머리 기호도 직접 적는다 | `[[" ○ ", 0], ["(현황)", 1], [" 내용", 2]]` |
| `header_rows` | `table`의 머리 줄 수(기본: 견본 표가 2줄 이상이면 1) | `"header_rows": 2` |
| `keep_header` | `true`면 머리 줄은 견본 글 그대로, `table`에는 내용 줄만 | `"keep_header": true` |
| `body_like` | 내용 줄 모양으로 쓸 견본 표 줄 번호(기본: 머리 줄 다음 줄) | `"body_like": 1` |
| `last_like` | 마지막 내용 줄(합계 등)에 쓸 견본 표 줄 번호 | `"last_like": 3` |
| `cols` | `table`의 칸 수(보통 줄 길이로 저절로). 견본 표와 다르면 첫·끝·가운데 칸 모양을 복사해 늘이거나 줄임 | `"cols": 5` |
| `widths` | 칸 너비 비율 — 준 대로 둠(없으면 도구가 내용에 맞춰 나눔) | `"widths": [1, 3, 3]` |
| `marker` | `false`면 견본 문단의 머리 기호를 붙이지 않고, 글의 `1.`·`Ⅰ.`·`가.`·`○`도 머리 기호로 보지 않고 글자 그대로 넣는다(제목 상자·요약 상자 같은 표 칸 글에도) | `"marker": false` |

- 밑줄·색 글씨처럼 견본 문단에 따로 있는 조각 모양은 `runs`로 조각 번호를 골라 쓴다.
- 참고 머리표의 `page_break`는 앞 참고와 한 쪽에 다 들어가지 않을 때만 쓰인다 — 다 들어가면 도구가 한 쪽에 모음(사용자 2026-11-10).
- 견본에 참고 머리표가 없으면 `[참고1] 제목`에 기본 양식의 참고 머리표를 서식째 가져와 쓴다(의뢰서 양식 등 — 사용자 2026-11-22).

## 판례·해석례 발췌 블록(참고 쪽에 — 사용자 2026-11-22)

```
{"case": "대법원 ○○○○. ○. ○○. 선고 ○○○○두○○○○ 판결", "gist": ["요지 원문", "둘째 문단"]}
{"interp": "법제처 ○○-○○○○, ○○○○. ○○. ○○. 회신", "q": "질의 원문", "reply": "회신 원문", "reason": "이유 원문"}
```
- 원문 확인한 글만(법령 검색 도구). 도구가 `- 대법원 …` 머리 줄과 `(판결요지) …`·`(질의)`·`(회신)`·`(이유)` 줄로 펼친다: 머리 줄의 `-`는 내어 써서 `대법원` 앞끝선 = `(판결요지` 앞끝선 = 둘째 줄 자리, 이름표는 글자 그대로(폭 맞추기 안 함), 본문 ○보다 1pt 작게·줄 간격 160%, 사건 사이 반 줄. 원문 인용이라 근거법령 조문처럼 자간으로만 끝선(줄 바꿈·끝 줄 내리기·'벌어진 줄' 지적 없음).
- `gist`·`q`·`reply`·`reason`은 글 하나 또는 목록(목록이면 둘째부터 이름표 없이 같은 자리).

## 문장 후보 시험(`build.py … --try 후보.json`)

'빈칸이 크게 벌어지는 줄'·'한 줄 줄이기 후보'를 고칠 때, 고쳐 쓸 문장 후보를 만들기와 같은 셈으로 미리 잰다(파일은 만들지 않음 — 사용자 2026-11-22).
```
[{"find": "점검 결과 시설 대부분이", "texts": ["후보 글 1", "후보 글 2"]}]
```
- `find`는 계획 블록 글의 일부(또는 `"block": 1부터 센 번호`), 후보는 블록 글 그대로(머리 기호를 빼면 원래 기호를 붙임). 결과: 후보마다 `통과`/`남음` — 줄 수·끝 줄 글자 수·어림 쪽 수, 남으면 넘어간 낱말과 줄일 폭. 통과한 후보를 계획에 넣고 다시 만든다.

## 값 옵션(맨 위에)

| 옵션 | 하는 일 |
|---|---|
| `body_pt` | (숫자, 기본 14) 표 글자의 기준인 본문 크기 — 표 글자는 이보다 3pt 작게. 사용자가 본문 크기를 따로 말했을 때만 넣는다 |
| `basis_first` | (기본 true) 근거법령을 1번으로 — 끄면(false) 옮기지 않고 근거법령 지적도 알림으로만 |
| `fit` | (기본 true) 표 맞춤·줄 맞춤·쪽 맞춤 전부 — 끄면(false) 자간·칸 너비·줄 간격·쪽 나눔을 맞추지 않음(네 글자 제목 붙이기·번호·이름표 폭 같은 글 손질은 아래 끄기 옵션으로 따로) |
| `line_pct` | (숫자, 100~300) 본문 줄 간격을 이 값으로 — 견본 ○·-·기호 없는 글 문단을 이 값으로, □ 제목·* ※ 줄은 같은 폭만큼 옮기고, 쪽 맞춤은 줄 간격을 줄이거나 넓히지 않는다. 예: 법률자문 의뢰서 `"line_pct": 190` |
| `narrative` | (true/false, 기본 false) 서술식 문서(문장으로 쓰는 문서 — 이 스킬을 부르는 다른 스킬이 넘김) — 괄호 이름표 폭 맞추기·괄호 글자 줄이기·강제 줄 바꿈(괄호·낫표 앞 `opener_breaks`, 연결어 앞 `connector_breaks`, 끝 줄 내리기 `push_down` — 한글은 줄 바꿈 앞 줄을 양쪽 정렬하지 않아 오른쪽이 빔)을 기본으로 끄고 본문 글 문단을 문단 보호(`keep_lines`)로. 못 고친 끝 줄·벌어진 줄은 '고쳐야 함'으로 문장 고치기를 안내. 켜려면 그 옵션을 true로 |

## 끄기 옵션(맨 위에, 모두 기본 true — 끌 때만 false)

| 옵션 | 하는 일 |
|---|---|
| `join_titles` | 네 글자 제목·이름표 붙여 쓰기 |
| `space_blocks` | □·Ⅰ. 앞 빈 줄 |
| `number_items` | 번호 매기기(Ⅰ. 1. 가. ①) |
| `push_down` | 끝 줄 한두 낱말을 위 줄 낱말과 함께 내려 7~10자로(끄면 올리기만 — 서술식 문서 기본 끔) |
| `opener_breaks` | 괄호·낫표·따옴표·화살표로 여는 덩어리가 줄 끝에서 갈라지면 기호 앞에서 줄 바꿈(서술식 문서 기본 끔) |
| `connector_breaks` | 줄 끝 연결어(+·및·또는·=·→)를 다음 줄 첫머리로(서술식 문서 기본 끔) |
| `align_labels` | 괄호 이름표 폭 맞추기 |
| `keep_groups` | □·○ 묶음을 한 쪽에(다음 문단과 함께 — 쪽 맞춤이 묶음째 넘기고 빈 줄을 좁힘) |
| `keep_heads` | keep_groups를 끈 문서에도 머리 문단(□·제목, 아래 문단이 더 들어가 시작하는 문단, ■ 제목·단위 줄)은 바로 아래 첫 문단과 함께 |
| `keep_lines` | 본문 글 문단을 문단 보호(쪽 경계에서 나누지 않음 — 서술식 문서 기본 켬, 그 밖은 끔) |
| `word_wrap` | 어절 단위 줄 바꿈 |
| `tighten_quotes` | 따옴표·낫표·가운데점 붙이기 |
| `one_space` | 머리의 고정폭 빈칸 둘을 장평 두 배 하나로·줄머리 빈칸을 여백으로 |
| `pull_corner` | 줄 첫머리 낫표 반 칸 당기기 |
| `line_fill` | 끝선에 조금 못 미친 한 줄·끝 줄을 자간으로 채우기 |
| `table_notes` | 표 뒤 ※를 표 끝선 ※ 모양으로 |
| `note_small` | *·※ 설명글 2pt 작게 + 아래 3pt |
| `paren_small` | 부연설명 괄호 작게(pt 수, 기본 2, 끄려면 0) |
| `colons` | 쌍점 앞뒤 한 칸·내어쓰기 |
| `label_hang` | (기본 끔) 켜면 옛 방식 — 개조식 괄호 이름표 줄의 둘째 줄을 이름표 `)` 뒤 첫 글자에(기본은 늘 `(` 자리, 사용자 2026-11-26) |
| `omit_dots` | 괄호 생략 표시 (중략)·(후략)을 `···`로(옮겨 쓰기처럼 글을 그대로 둘 때 false) |
| `keep_numbers` | 숫자 꾸밈말 묶음 빈칸 |
| `square_small` | □ 기호 2pt 작게 |
| `date_gap` | 날짜·부서 줄 아래(요약 상자 위) 1pt |

## 구역(가로 쪽)

`{"section": "가로"}` 블록(또는 아무 블록에 `"section": "가로"`)부터 새 구역 — 첫 구역의 쪽 설정·머리말·꼬리말·쪽 번호를 그대로 쓰고 방향만 가로로, `{"section": "세로"}`로 돌아온다. 쪽 번호는 이어지고, 그 구역의 쪽 너비 표는 새 본문 폭(가로 257mm)에 맞춰 칸 너비를 비율대로 넓히며, 표 위 ■ 제목·단위 줄도 표와 같은 구역으로 간다. 쪽 맞춤·줄 맞춤은 구역마다 그 쪽 크기로 잰다. 검사만·정돈·칸 채우기도 모든 구역을 본다(칸 채우기 번호는 구역을 이어서 셈).

## 아직 못 하는 것(한글에서 하도록 안내)

견본에 없는 글꼴·크기·색(그 모양 문단을 견본에 넣어 다시 올려 달라고 함) · 표 밖 그림(표 칸 배경 그림·기본 양식 표지 마크·슬로건은 됨)과 머리말·꼬리말 글 바꾸기 · 견본의 둘째 구역부터의 문단을 견본으로 쓰기(새 구역은 위 `section`으로 — 첫 구역 문단 모양을 씀) · 표 칸 안 자간 맞춤(표는 글자 크기·칸 너비·'한 줄로 입력', 폭을 내준 칸 -9%까지만) · 쉼표로 이은 칸 글을 `· 항목` 줄로(계획에서 나눔).

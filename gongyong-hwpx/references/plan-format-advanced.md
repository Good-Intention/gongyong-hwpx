# 계획 파일 — 덜 쓰는 항목

> 한 주제 = 한 파일 한 곳 — 이 파일은 계획 파일의 덜 쓰는 항목만. 조각 모양을 직접 고르거나, 견본 표의 줄·칸·너비를 정하거나, 머리 기호·자동 처리를 끌 때만 읽는다.

## 블록 항목(번호 꼴 `{"like": 번호, …}` 블록에)

| 항목 | 뜻 | 예 |
|---|---|---|
| `title` · `unit` | 표 블록의 ■ 제목·기준·단위 줄(기호 꼴에서는 표 앞에 `■ 제목` 줄로 써도 같음). 도표(`flow`)에서는 상자 위 `< 제목 >` | `"title": "세부사업별 예산 현황"` |
| `runs` | 조각마다 모양을 직접 고를 때 `[[글, 조각 번호], …]` — 머리 기호도 직접 적는다 | `[[" ○ ", 0], ["(현황)", 1], [" 내용", 2]]` |
| `header_rows` | `table`의 머리 줄 수(기본: 견본 표가 2줄 이상이면 1) | `"header_rows": 2` |
| `keep_header` | `true`면 머리 줄은 견본 글 그대로, `table`에는 내용 줄만 | `"keep_header": true` |
| `body_like` | 내용 줄 모양으로 쓸 견본 표 줄 번호(기본: 머리 줄 다음 줄) | `"body_like": 1` |
| `last_like` | 마지막 내용 줄(합계 등)에 쓸 견본 표 줄 번호 | `"last_like": 3` |
| `cols` | `table`의 칸 수(보통 줄 길이로 저절로). 견본 표와 다르면 첫·끝·가운데 칸 모양을 복사해 늘이거나 줄임 | `"cols": 5` |
| `widths` | 칸 너비 비율 — 준 대로 둠(없으면 도구가 내용에 맞춰 나눔) | `"widths": [1, 3, 3]` |
| `marker` | `false`면 견본 문단의 머리 기호를 붙이지 않고, 글의 `1.`·`Ⅰ.`·`가.`·`○`도 머리 기호로 보지 않고 글자 그대로 넣는다(제목 상자·요약 상자 같은 표 칸 글에도) | `"marker": false` |

- 밑줄·색 글씨처럼 견본 문단에 따로 있는 조각 모양은 `runs`로 조각 번호를 골라 쓴다.
- 참고 머리표의 `page_break`는 앞 참고와 한 쪽에 다 들어가지 않을 때만 쓰인다 — 다 들어가면 도구가 한 쪽에 모음(사용자 2026-11-10).

## 값 옵션(맨 위에)

| 옵션 | 하는 일 |
|---|---|
| `body_pt` | (숫자, 기본 14) 표 글자의 기준인 본문 크기 — 표 글자는 이보다 3pt 작게. 사용자가 본문 크기를 따로 말했을 때만 넣는다 |
| `basis_first` | (기본 true) 근거법령을 1번으로 — 끄면(false) 옮기지 않고 근거법령 지적도 알림으로만 |
| `fit` | (기본 true) 표 맞춤·줄 맞춤·쪽 맞춤 전부 — 끄면(false) 자간·칸 너비·줄 간격·쪽 나눔을 맞추지 않음(네 글자 제목 붙이기·번호·이름표 폭 같은 글 손질은 아래 끄기 옵션으로 따로) |

## 끄기 옵션(맨 위에, 모두 기본 true — 끌 때만 false)

| 옵션 | 하는 일 |
|---|---|
| `join_titles` | 네 글자 제목·이름표 붙여 쓰기 |
| `space_blocks` | □·Ⅰ. 앞 빈 줄 |
| `number_items` | 번호 매기기(Ⅰ. 1. 가. ①) |
| `push_down` | 끝 줄 한두 낱말을 위 줄 낱말과 함께 내려 7~10자로(끄면 올리기만) |
| `align_labels` | 괄호 이름표 폭 맞추기 |
| `keep_groups` | □·○ 묶음을 한 쪽에(다음 문단과 함께) |
| `word_wrap` | 어절 단위 줄 바꿈 |
| `tighten_quotes` | 따옴표·낫표·가운데점 붙이기 |
| `one_space` | 머리의 고정폭 빈칸 둘을 장평 두 배 하나로·줄머리 빈칸을 여백으로 |
| `pull_corner` | 줄 첫머리 낫표 반 칸 당기기 |
| `line_fill` | 끝선에 조금 못 미친 한 줄·끝 줄을 자간으로 채우기 |
| `table_notes` | 표 뒤 ※를 표 끝선 ※ 모양으로 |
| `note_small` | *·※ 설명글 2pt 작게 + 아래 3pt |
| `paren_small` | 부연설명 괄호 작게(pt 수, 기본 2, 끄려면 0) |
| `colons` | 쌍점 앞뒤 한 칸·내어쓰기 |
| `label_hang` | 이름표 뒤 내어쓰기 |
| `omit_dots` | 괄호 생략 표시 (중략)·(후략)을 `···`로(옮겨 쓰기처럼 글을 그대로 둘 때 false) |
| `keep_numbers` | 숫자 꾸밈말 묶음 빈칸 |
| `square_small` | □ 기호 2pt 작게 |
| `date_gap` | 날짜·부서 줄 아래(요약 상자 위) 1pt |

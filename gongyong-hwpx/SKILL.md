# 공무원 한글문서 편집스킬 (HWPX)

견본 한글 파일의 문단을 복사해 글만 바꿔 끼운다(견본에 없는 서식은 생기지 않고, 자간·줄 간격·칸 너비·쪽 나눔은 도구가 맞춤). 파이썬과 lxml(`pip install lxml`)이 필요하고, 경로는 스킬 폴더 기준(`python <스킬폴더>/scripts/…`).

**늘 지킬 것**: ① 근거법령은 1번(확인된 법령만) ② 본문은 개조식, 명사형 끝맺음(`~함`·`~임`·명사) ③ build.py의 '고쳐야 함'을 다 지운 뒤 건넨다 — 다시 만들기는 두 번까지, 그래도 남으면 무엇이 왜 남았는지 알리고 건넨다 ④ 건넬 때마다 build.py 출력의 `## 사용자에게 전할 말`을 그대로 옮긴다.

## 0. 모드(읽을 파일은 모두 `references/`)

| 사용자 말 | 모드 | 읽을 파일 |
|---|---|---|
| 써 줘·만들어 줘·이 양식대로 | **작성**(올린 hwpx는 모양만 빌리는 견본, 코드를 못 돌리는 앱도) | `write.md` → `style-guide.md` → `plan-format.md`(견본이 없으면 + `basic-report-map.md`) |
| 이미 쓴 hwpx + 정돈해 줘·다듬어 줘·줄 맞춰 줘 | **정돈**(그 파일을 고침, 보고서 원칙은 적용하지 않음) | `tidy.md`, 도구는 `scripts/tidy.py`만 |
| 칸을 채우는 양식(신청서·안내서) + 이 칸에 써 줘, 표 안 보고서 | **양식 칸 채우기**(표·칸은 그대로, 칸 글·칸 안 표·그림만) | `form-fill.md`, 도구는 `scripts/form_fill.py` |
| 이미 쓴 hwpx + 검사해 줘·서식 봐 줘(새로 쓰라는 말이 없으면) | **검사만**(파일을 바꾸지 않음) | `review.md`, 도구는 `scripts/review.py` |

- 애매하면(hwpx만 올리고 "이거 손봐 줘") 번호로 묻는다: ① 이 내용으로 새로 쓰기(작성 — 짜임·문장까지) ② 그대로 정돈(글은 그대로, 줄 나눔·간격·맞춤만). PDF·그림 문서는 정돈 대신 '옮겨 쓰기'(tidy.md 끝).
- 글자·숫자 몇 군데, 표 줄 하나 같은 **부분 수정**은 모드가 아니다 — 파일 속 글을 직접 고치고 그 문단의 `linesegarray`를 지워 한글이 다시 나누게.

필요할 때만: 짧은 계획서(추진계획(안))가 아닌 종류 → `doc-types.md`(그 종류 한 행) · 표지 → `cover.md` · 도표·그림·참고 조문 발췌 → `boxes-figures.md` · 조각 모양·견본 표 줄·칸 너비·자동 처리 끄기 → `plan-format-advanced.md` · 낱말 → `words.md` · 만들기 알림 뜻 → `auto-fit.md` · 정돈 알림 뜻 → `tidy-detail.md` · 규칙 내력 → `history.md` · 다른 부서 기준값(본문 pt·자간 범위 등) → `assets/profile.json`.

## 전달하기

- 결과 파일과 쉬운 말 3줄 안팎: 어떤 양식으로 만들었는지, 자동으로 맞춘 것, 채울 자리표시, "한글에서 열어 보시고 고칠 곳을 말씀하시거나 고친 파일을 올려 주세요." 여백 안내(④)에는 위·아래 여백이 온나라 서식마다 달라 쪽 끝은 붙여 넣은 뒤 확인하시라고 덧붙인다.
- 개발 용어(JSON·XML·run) 없이 존댓말. 견본의 머리말·꼬리말 글은 그대로 남으므로 다른 부서·날짜가 있으면 알린다.
